# Generative UI

CopilotKit supports multiple approaches to generative UI:

  * [Display Only](https://docs.copilotkit.ai/generative-ui/display) — Agent renders read-only components
  * [Interactive](https://docs.copilotkit.ai/generative-ui/interactive) — Agent renders interactive components with callbacks
  * [Tool Rendering](https://docs.copilotkit.ai/crewai-crews/generative-ui/tool-rendering) — Map backend tool calls to UI components
  * [State Rendering](https://docs.copilotkit.ai/crewai-crews/generative-ui/state-rendering) — Render UI from agent state
  * [MCP Apps](https://docs.copilotkit.ai/crewai-crews/generative-ui/mcp-apps) — Model Context Protocol integrations
  * [A2UI](https://docs.copilotkit.ai/crewai-crews/generative-ui/a2ui) — Agent-to-UI protocol
  * [Your Components](https://docs.copilotkit.ai/crewai-crews/generative-ui/your-components) — Use your own component library
