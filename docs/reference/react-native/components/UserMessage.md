# UserMessage

A right-aligned user chat bubble that renders plain text, with an optional timestamp.

Open your coding agent in your project's folder, or in an empty folder for a new app.This runs in a coding agent on your computer.

## Overview

`UserMessage` renders a right-aligned chat bubble for user turns. Content is shown as plain text (no Markdown), with white text on a primary-color background. Useful when building a custom chat UI on top of the headless [`CopilotChat`](https://docs.copilotkit.ai/reference/react-native/components/CopilotChat).
