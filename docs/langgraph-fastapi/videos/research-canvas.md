Open your coding agent in your project's folder, or in an empty folder for a new app.This runs in a coding agent on your computer.

The clip above shows [Tako](https://tako.com) powering an Agent-Native Research canvas—generating interactive visuals from its index of trusted, real-time data spanning finance, sports, politics, and more.

Dive deeper to explore Tako's [documentation](https://docs.tako.com/documentation/integrations-and-examples/langgraph-copilotkit) and their open-source [Research Canvas example](https://github.com/TakoData/tako-copilotkit) built with CopilotKit, LangGraph, Tako, and Tavily.

This recording uses CopilotKit v1 APIs. It walks through building an agentic Research Canvas with LangGraph. For the current implementation, you can [run the CopilotKit v2 app](https://examples-coagents-research-canvas-ui.vercel.app/) or browse the [current CopilotKit v2 source code](https://github.com/CopilotKit/CopilotKit/blob/main/examples/v1/research-canvas/readme.md). When updating an older app, use the [v1 to v2 migration guide](https://docs.copilotkit.ai/langgraph-fastapi/migrate/v2).
