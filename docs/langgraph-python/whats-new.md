## January 22, 2025#

### Full MCP Apps Support!#

CopilotKit and AG-UI make MCP Apps usable inside real, user-facing applications. [More →](https://docs.copilotkit.ai/langgraph-python/whats-new/mcp-apps-support)

### LangGraph Deep Agents now compatible with CopilotKit!#

Leverage LangGraph Deep Agents to build sophisticated agentic applications with CopilotKit. [More →](https://docs.copilotkit.ai/langgraph-python/whats-new/langgraph-deep-agents)

  
  


## December 15, 2025#

### A2UI Launches Today!#

CopilotKit has been working with Google on A2A and A2UI integrations, and is proud to be a launch partner for A2UI. [More →](https://docs.copilotkit.ai/langgraph-python/whats-new/a2ui-launch)

Confused about "A2UI" and "AG-UI"? That's understandable! Despite the naming similarities, they are quite different and work well together. 

[Learn more](https://copilotkit.ai/ag-ui-and-a2ui)

### CopilotKit v1.50#

CopilotKit v1.50 is now available, with brand new interfaces, streamlined internals, and no breaking changes. [More →](https://docs.copilotkit.ai/langgraph-python/whats-new/v1-50)

### Generative UI Spec Support#

CopilotKit now supports all major Generative UI specifications - A2UI, Open-JSON-UI, and MCP Apps. [More →](https://docs.copilotkit.ai/langgraph-python/whats-new/generative-ui-spec-support)

### A2A and MCP Handshake#

AG-UI now includes handshakes with both A2A and MCP protocols, enabling seamless interoperability across the full agentic stack. [More →](https://docs.copilotkit.ai/langgraph-python/whats-new/a2a-mcp-handshake)
